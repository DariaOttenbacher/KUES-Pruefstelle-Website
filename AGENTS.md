# Regeln für die KI

1. Änderungen sollen klein bleiben und funktionierenden Code nicht unnötig verändern.
2. Vor jeder Änderung soll die betroffene Datei genannt werden.
3. Die bestehende Struktur des Projekts soll beibehalten werden.
4. API-Keys dürfen nicht im Frontend gespeichert werden.
5. Neue Bibliotheken sollen nur hinzugefügt werden, wenn sie wirklich notwendig sind.
6. Fehlermeldungen sollen auf der Webseite sichtbar sein, nicht nur in der Konsole.
7. Codeänderungen sollen kurz und verständlich erklärt werden.
